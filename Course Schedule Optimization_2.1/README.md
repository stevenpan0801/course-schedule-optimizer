# 选课优化 2.1

使用 2026-10-27 更新的数据库（无开放/关闭字段），所有班级参与规划。按用户确认，已在随包数据库中删除 CHI1000 的 Tutorial 必需记录，CHI1000 只选 Lecture。源文件夹未修改。

## 启动

Python 3.10 或以上。在本文件所在目录打开终端：

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

PyCharm 用户应在项目所用的 Python 虚拟环境中执行以上命令。requirements.txt 是依赖列表，不是可运行脚本。

## 使用

1. 在左侧选择课程，系统实时统计学分；满足 12–18 学分后可生成方案。
2. 在“排课偏好与不可用时间”中设置时间或教师偏好。早八可选无偏好、尽量避免、优先安排、禁止安排；额外禁排时间直接在表格中增删行。
3. 点击“生成推荐方案”，在同一个课表区域切换前三个推荐结果。
4. 点击“以此方案调整班级”进行修改，每次改班自动复核；也可直接打开“手动调整班级”从空白开始选班。关闭开关可回到推荐结果，手动选择仍保留。
5. 在课表上方选择教学周；手动方案与检查结果在切周后保留。课表下方可展开本周明细，导出 CSV 或完整学期 JSON。
6. 修改课程、偏好或数据库后旧推荐结果隐藏，需重新生成。无效方案不能预览或导出。

无第三方库也可使用核心算法：

```bash
python3 cli.py request.json > result.json
python3 cli.py --check result.json
python3 -m unittest test_optimizer -v
```

`request.json` 是可修改示例。`blocked` 是 `[星期,开始分钟,结束分钟]` 的数组，例如 `[[3,1080,1260]]` 表示每周三 18:00–21:00。

## 文件职责

- `model.py`：只读数据库适配、输入结构、同一班同一星期/时间/日期的多教室记录合并。
- `optimizer.py`：回溯搜索与分支定界，返回 top 3。
- `checker.py`：独立复核，不引用优化器；逐个实际日期检查课时重叠、组件、学分及禁排要求。
- `app.py`：Streamlit 界面，串联优化和检查，支持手动调整。
- `timetable.py`：按显示周过滤数据，以实际起止时间分割表格，绝不挪动课程以消除显示重叠。
- `query_courses.py`：适配新版无状态数据库的查询函数。
- `cli.py`：算法与检查器的命令行入口。
- `test_optimizer.py`、`test_ui.py`：核心测试与界面测试。

## 明确的评分公式

三个类别（早八、星期、教师）等权。未设置类别不参与总分；全留空时所有合法方案同为 50 分，取确定顺序中的前三个。

对于早八或某个已评分的星期，令 r 为 0–5 喜好分，N 为所选方案整个学期该类实际上课次数，M 为所有组件各自候选班级的最大该类次数之和。M 固定于本次请求（硬筛选后），不随搜索方案变化。取 q=N/M；M=0 时 q=0。

该项得分 = 20 × [(5−r)×(1−q) + r×q]。

因此 r=0 推动减少，r=5 推动增加。星期类别为所评分星期的平均值。该目标减少不喜欢那天的课次；“完全空出一天”请使用禁止整天。M 是一个可计算上界，受其他课程冲突影响，可能无法同时达到，所以 100 分不一定可达。不同请求的分数不适合横向比较。

教师类别：只纳入候选教师中有用户评分的课程组件；各班的多位教师评分取平均，未评分或姓名未知的教师按 2.5；再对纳入的组件取平均并乘 20。姓名偏好按课程输入，自动映射至相关组件。当前不提供权重设置。

一条每周两次的课程安排计两次；不同教学日期对应的真实次数分别计算。同班同时间同日期的多教室记录合并为一次，显示所有教室。

## 正确性与边界

- 搜索完成：在当前候选数据、约束和上述目标下证明 top-k 分数最优；同分方案允许任取 k 个。
- 达到时限且有解：返回当前最佳，不宣称已最优。
- 达到时限且无解：只是尚未找到，不能宣称无解。
- 数据库缺少必需组件时阻止自动排课。Python 接口保留显式 allow_missing_components 豁免，网页不提供隐式豁免。
- 每次运行重新读取数据库，不依赖开放状态。更新数据库时替换同名文件即可；必须保留本版表结构及 CHI1000 组件更正。
- 数据库没有 Lecture/Tutorial 班级绑定关系，没有个人先修修读记录；无法验证这些规则，也不等于在学校 SIS 注册成功。
- 相邻两课结束/开始时间相同视为不冲突；没有通勤缓冲、节假日、调课或单独教学周例外数据，仅按星期和起止日期。
- 同时段多教室按一次课处理并警告，未擅自选择真实教室。
- 没有修改原 1.0 文件夹；这是可独立运行的 2.1 完整版本。原检查流程已提取并增强为 checker.py，不依赖原 test_app.py。

## 验证

14 项核心测试通过，包含 25 组随机偏好与完整枚举的 top-3 分数对照、早八/星期偏好反转、教师偏好、硬约束、教学日期、超时区分、多教室去重和真实数据库。
界面测试覆盖自动排课、载入手动检查、修改输入后的结果失效、无解与学分错误。

测试环境：Python 3.13、Streamlit 1.66.1、Pandas 3.1.0。依赖下限未逐版本测试。

本版沿用 2.0 的数据库（包括 CHI1000 组件修正）、排课算法与独立检查器，数据库内容未改动。新增页面回归检查覆盖方案切换、手动检查持久化、缺失组件、输入变化失效、无解与学分限制；额外测试了禁排表格的有效和倒置区间。

验证方式：Streamlit AppTest 界面测试及 14 项核心测试通过。当前制作环境禁止绑定本地服务端口，因此未进行浏览器实机视觉验收。
